# Skill: Git Terminal Execution

<description>
Provides explicit terminal commands for Git synchronization without MCP servers.
</description>

<commands>
- Fetch & Merge dev: `git fetch origin dev && git merge origin/dev`
- Push feature branch: `git push origin HEAD`
- Checkout & Sync dev: `git checkout dev && git pull origin dev`
- Merge feature into dev: `git merge <feature-branch>`
</commands>
